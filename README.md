## Customer Shopping Behavior Analysis 

## Project Overview
This project focuses on analyzing customer shopping behavior using transactional data.
The objective is to uncover insights related to customer demographics, spending patterns,
product preferences, discounts, and subscription behavior to support data-driven
business decisions.

---

##  Dataset Information
- Records: ~3,900 customer transactions  
- Features include:
  - Customer details (Age, Gender, Location, Subscription Status)
  - Purchase details (Category, Item Purchased, Amount, Season)
  - Shopping behavior (Discount Applied, Review Rating, Purchase Frequency)
- Missing values were handled during data cleaning

---

##  Tools & Technologies Used
- **Python** – Data cleaning & exploratory data analysis  
- **SQL** – Business-level data analysis and querying  
- **Power BI** – Interactive dashboard and visual storytelling  
- **GitHub** – Project version control and portfolio showcase  

---

##  Data Cleaning & Preparation
- Handled missing values in review ratings
- Standardized column names for consistency
- Created derived features such as age groups and customer segments
- Removed redundant columns
- Prepared cleaned data for SQL and Power BI analysis

---

##  Analysis Performed
- Revenue analysis by gender and age group
- Customer segmentation (New, Returning, Loyal)
- Subscription vs non-subscription spending comparison
- Discount impact on purchase behavior
- Product performance based on ratings and sales

---

## Key Insights
- Subscribers contribute higher average revenue than non-subscribers
- Loyal customers generate a significant portion of total sales
- Discounts increase purchase volume but impact profit margins
- Certain age groups show higher spending behavior
- Top-rated products align closely with higher sales volume
